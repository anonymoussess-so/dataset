# 强破坏地震 - 特别严重受灾程度说明

## 文件夹总体说明

`destructive_earthquake/level_4` 文件夹表示一次完整的“强破坏地震 - 特别严重”灾情样本集合。该文件夹不是某个单独基站或单条链路的记录，而是把该灾情等级下的通信制式、通信资源节点、资源画像、节点状态和用户业务会话统一组织在一起，用于描述该等级下通信资源整体受损和业务质量变化情况。

该文件夹包含 10 个 `resource_profile.json`、116 条 `cell_info.jsonl` 基站/节点记录，以及 240,000 条 `business_users.jsonl` 用户业务会话记录。它可以作为强化学习环境中的一个场景切片，用来构建状态输入、动作约束和奖励计算依据。

## 等级定义与灾害强度说明

| 项目 | 内容 |
|---|---|
| 受灾等级目录 | `level_4` |
| 中文等级 | 特别严重 |
| 灾害类型 | `earthquake` |
| 灾情强度说明 | 地震强度可理解为 7.0 级及以上强震影响，核心区可能出现大面积倒站、断电和光缆中断，公网能力弱或不可用，应急通信以卫星、短波和临时 Mesh 为主。 |
| 通信影响概述 | 残余公网极弱或不可用，主要依赖卫星、短波、应急车、临时 WiFi Mesh。 |

该等级采用 5×12 网格建模，完整受灾面积约 480 km²，单个网格约 8.000 km²。

该等级的含义不仅由灾害强度定义，也由本文件夹中的实际数据共同体现：节点状态分布反映基础设施受损程度，连接成功率和失败率反映用户接入可靠性，带宽和覆盖半径反映资源能力下降情况，时延、重传和乱序反映业务质量退化情况。

## 该文件夹内数据如何共同描述一次灾情

| 数据层级 | 对应文件或目录 | 在本等级中的含义 |
|---|---|---|
| 灾害等级层 | `severity_description.md` | 汇总 `level_4` 的实际统计结果、资源影响和训练用途。 |
| 通信制式层 | `cellular_5g_700mhz`、`satellite_ka`、`wifi6_mesh`、`shortwave_hf` | 表示该等级下可参与调度的蜂窝、卫星、局部接入和保底通信能力。 |
| 资源类型层 | 各通信制式下的基站/节点类型目录 | 表示不同部署形态的能力差异，例如宏站、背包微站、卫星终端、Mesh 节点和短波电台。 |
| 资源画像层 | `resource_profile.json` | 汇总该资源类型的带宽、覆盖、功率、连接成功率、站点状态和有效覆盖网格。 |
| 节点样本层 | `cell_info.jsonl` | 每行表示一个具体基站/节点，记录位置、损毁状态、运行状态、覆盖能力和连接统计。 |
| 业务会话层 | `business_users.jsonl` | 每行表示一次用户业务会话，记录业务类型、数据量、时延、吞吐、重传、乱序和连接结果。 |

## 综合判定方法

该等级不是由单个字段直接决定，而是由该文件夹下资源画像、节点状态和业务会话共同统计得到。判断时主要关注以下维度：

| 判断维度 | 对应数据字段 | 在本文件夹中的作用 |
|---|---|---|
| 站点离线比例 | `operational_status=offline`、`offline_station_count` | 判断基础设施中断程度。 |
| 站点受损比例 | `is_damaged`、`damage_level`、`damaged_station_ratio` | 判断物理损坏范围。 |
| 连接可靠性 | `connection_success_rate`、`connection_failure_rate` | 判断用户能否成功接入。 |
| 带宽保持能力 | `downlink_bandwidth_mbps`、`uplink_bandwidth_mbps` | 判断链路承载能力是否下降。 |
| 覆盖保持能力 | `coverage_radius_km`、`effective_covered_grid_count` | 判断通信覆盖是否收缩。 |
| 业务质量退化 | `latency_ms`、`retransmission_packet_count`、`reordering_packet_count` | 判断实际业务体验是否下降。 |

## 与强化学习训练的关系

在强化学习环境中，`disaster_severity=level_4` 是场景级状态变量。模型不能只根据等级编号做决策，还需要结合本文件夹中的实际统计结果判断资源可用性。该等级对训练过程的作用包括：

| 训练环节 | 作用 |
|---|---|
| 状态输入 | 将灾害强度、节点状态、链路质量和业务需求编码为模型输入。 |
| 动作约束 | 离线节点和严重受损节点不能作为有效承载资源，低带宽链路不应承载高需求业务。 |
| 奖励计算 | 覆盖恢复、连接成功率、业务吞吐、时延、重传和资源消耗共同决定奖励。 |
| 策略评估 | 可用于评估模型在该灾害等级下的资源选择、链路组织和业务保障能力。 |

## 业务会话分布补充
